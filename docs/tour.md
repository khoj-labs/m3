# Tour of m3

For anyone, human or assistant, who wants to understand the repo without reading it all. Two depths: **TL;DR** and **Full tour**.

Take every number from the repo, never from this page: run `npm run check:gallery` for component counts, and look at `src/components/ui` and `src/boilerplate`.

## TL;DR

Write at most 8 lines covering:

1. **What:** Material Design 3 components for React, built on shadcn/ui (Base UI) and restyled with M3 tokens, plus hand-built extras shadcn doesn't ship, plus an application boilerplate.
2. **What's in it:** component and boilerplate counts (from `npm run check:gallery`).
3. **See it:** the live gallery at https://m3.khojlabs.com/gallery, or locally `npm run dev` then `/gallery`. One page with tabs for Components (every variant and state), Page components (app shell, headers, states) and Utils (interactive demos).
4. **Theme it:** all visual values live in `src/theme.css`; see [theming.md](theming.md).
5. End by offering the full tour.

## Full tour

Walk through these in order, a few lines each, and stop to ask what to go deeper on.

1. **Purpose.** Read the README's "What" section.
2. **Theme system.** One file, `src/theme.css`: seed hues, `--md-*` color roles (light and dark), shape, type, motion, elevation. `src/themes/*.css` are alternatives; `npm run check:theme` validates them. Spec: [theming.md](theming.md).
3. **Components.** `src/components/ui`: files generated by the shadcn CLI, plus the hand-built ones (find them: they are the files not in the shadcn registry, listed in the README). Tokens reach Tailwind through `src/index.css` (`bg-md-*`, `shadow-elevation-*`, `ease-emphasized`).
4. **Boilerplate.** `src/boilerplate`: `common`, `layouts`, `pages`, and `utils` (logger, analytics facade, HTTP client, cache, API error codes). Ported from react-gold-tsx without the libraries. Override points are in the README.
5. **Galleries.** `/gallery` is one tabbed page built from m3's own components. `npm run check:gallery` fails if something has no section.
6. **Commands and conventions.** The commands table and key rules in [AGENTS.md](../AGENTS.md), the details in [conventions.md](conventions.md); "done" means lint, typecheck, build, `check:gallery` and `check:theme` pass.
7. **Next steps.** Offer to start the dev server, or to walk through theming, a specific component, or the boilerplate in detail.
