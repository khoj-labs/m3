# Worker instructions (one component per worker)

You migrate ONE component of m3 from Radix UI to Base UI, only if Base UI is indistinguishable from the live Radix version. Your task id is given in your prompt (`C-<component>`).

0. **Get on the factory branch.** Your worktree may start from `main`. Run `git merge --ff-only factory/base-ui` first so `factory/tasks.json` and this file exist. Then `npm ci`.
1. **Read** your entry in `factory/tasks.json` plus its top-level `globalRules`, `protocol` (6 steps), `interactionChecklist`, `resultSchema` and `reference`; also `AGENTS.md` and `docs/conventions.md`. Follow the protocol in order. Do not skip the safety check: search GitHub issues and discussions (mui/base-ui, shadcn-ui/ui, radix-ui/primitives), Reddit, Hacker News and blogs for people who hit problems moving this component from Radix to Base UI. Cite URLs. Query the GitHub issue trackers directly (for example `https://github.com/mui/base-ui/issues?q=<component>` through a fetch), not only general web search.
2. **Baseline**: reference is https://m3.khojlabs.com/gallery#components then `document.getElementById('<section id>').scrollIntoView()`. Local build: `npm run dev -- --port <devPort>`, open `http://localhost:<port>/gallery#components`. Take real screenshots at 1280x900 and 390x844 (resize_window) of every variant and state on both, and compare them. Do not infer "looks the same" from identical class names; look at pixels.
3. **Browser etiquette**: other workers share the browser. Always create your own tab (`tabs_create_mcp`), never touch other tabs, close yours at the end. The browser is in system dark mode; light cannot be emulated, so record modes as `["dark"]`.
4. **Decide**: any perceptible difference in look, feel, interaction, accessibility or API means do NOT switch. Restore files (`git checkout`), write the result as `flagged (kept on Radix)` with `reasonNotMoved`, and commit only `factory/results/<task id>.json`. No differences and no high safety finding: do the `swap`, update `consumerFiles`, run `npm run lint:fix`, lint, typecheck, build and `check:gallery` (all must pass), commit `Move <component> to Base UI`, outcome `migrated`. If the radix-nova and base-nova registry files are identical, outcome `no-op`.
5. **Result file** `factory/results/<task id>.json` per `resultSchema`; commit it with your work. Never edit `factory/tasks.json`, `components.json` or `package.json`; never push, deploy or open pull requests; never touch files outside the task's `file` and `consumerFiles`.
6. **Report** (short): outcome, safety severity with URLs, every difference (or "none") with how to reproduce, consumers touched, API changes, gates, commit sha. Say "not checked" for anything you did not do.
